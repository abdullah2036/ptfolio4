Open index.html in a browser (Chrome, Edge, Safari or Firefox).
  - index.html    the portfolio (ASCII portrait + scroll-driven worm transitions)
  - gallery.html  the event gallery (24 photos)
  - assets/       portrait data, project screenshots, certificates, gallery photos

To publish: upload the whole folder as-is to any static host (Vercel, Netlify, GitHub Pages).
